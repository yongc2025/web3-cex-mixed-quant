# Web3链上+CEX混合量化策略工具
## 项目功能
1. 对接以太坊节点，爬取链上大额转账/资金流向信号
2. 融合CEX行情数据，实现链上信号驱动策略
3. 支持币安/Coinbase多交易所API对接
4. ClickHouse高效存储链上+CEX时序数据
5. 策略实时信号告警

## 技术栈
Python、Web3.py、ClickHouse、WebSocket、以太坊节点
